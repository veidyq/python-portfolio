# pricewatch — мониторинг цен конкурентов

Собирает цены с сайтов конкурентов, хранит историю в SQLite и выгружает
сравнение в Excel с подсветкой отклонений.

## Что делает

1. Читает конфиг со списком магазинов, товаров и своей цены.
2. Обходит страницы магазина (включая пагинацию), разбирает карточки товаров.
3. Сопоставляет найденный товар с товаром из конфига по нормализованному названию.
4. Считает отклонение в процентах и определяет, дороже вы или дешевле.
5. Складывает замер в SQLite — при следующем прогоне видно, изменилась ли цена.
6. Пишет отчёт: текст в консоль, `report.csv` и `report.xlsx` с подсветкой.

## Запуск

```bash
python pricewatch.py demo_data/config.json
```

Без сети и без установки зависимостей: `demo_data/` содержит сохранённые
страницы пяти магазинов, включая один битый.

```
Позиций: 9. Страниц обойдено: 5. Вы дороже в 2 из них.
Предупреждений: 1
  ! Магазин «Без цен»: на страницах нет карточек товаров
```

## Технические решения

| Задача | Решение |
|---|---|
| Разбор HTML без BeautifulSoup | `html.parser` со стеком тегов и извлечением карточек |
| Сопоставление товаров | нормализация названия (регистр, пунктуация, хвосты вида «1 шт») |
| Пагинация | детект «следующая страница» по ссылкам, до `pages` итераций |
| Битый сайт | исключение ловится на уровне магазина, прогон продолжается |
| Excel без openpyxl | генерация OOXML вручную и упаковка в zip |
| Подсветка строк | условное форматирование через `dxf` в стилях книги |
| Повторные запросы | 3 попытки с нарастающей паузой |

## Структура

```
pricewatch.py            CLI, парсинг, отчёт
demo_data/config.json    список магазинов и товаров
demo_data/*.html         сохранённые страницы для офлайн-запуска
prices.db                история замеров (создаётся автоматически)
```
