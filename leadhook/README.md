# leadhook — Telegram-бот приёма заявок

Бот записывает клиентов на услугу: меню, пошаговый диалог, валидация,
сохранение заявки в CSV и уведомление владельцу в Telegram.

## Что делает

1. `/start` — приветствие и меню услуг.
2. Диалог по шагам: имя → услуга → телефон → удобное время.
3. Каждый ответ проверяется; на ошибку бот переспрашивает, а не падает.
4. Готовая заявка пишется в CSV и отправляется владельцу сообщением.

## Запуск

Демо без токена и без сети — вся логика диалога в консоли:

```bash
python leadhook.py --demo --export leads.csv
```

Живой режим:

```bash
python leadhook.py --token <BOT_TOKEN> --admin <CHAT_ID>
```

Токен можно держать в `.env` (см. `.env.example`), чтобы не светить в командной строке.

## Технические решения

| Задача | Решение |
|---|---|
| Диалог | явный автомат состояний `user_id → шаг`, без вложенных `if` |
| Валидация телефона | нормализация к `+7XXXXXXXXXX`, мусор и неверная длина отбраковываются |
| CSV и Excel | запись в UTF-8 с BOM — Excel не ломает кириллицу |
| Значения по умолчанию | шаг подставляет рекомендуемый вариант, если пользователь не ответил |
| Проверка без Telegram | `--demo` прогоняет сценарий целиком, сеть не нужна |
| Секреты | `.env` в `.gitignore`, в репозитории только `.env.example` |

## Структура

```
leadhook.py        бот, автомат диалога, экспорт, demo-режим
.env.example       шаблон переменных окружения
leads.csv          заявки (создаётся автоматически, в git не попадает)
```
